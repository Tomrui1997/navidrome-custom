## 四、缺陷清单与修复

| # | 级别 | 缺陷 | 根因 | 修复 | 复测 |
| --- | --- | --- | --- | --- | --- |
| 1 | **P0** | 同步「假成功」：显示同步完成但一个文件没下 | baidupcs 拉不到目录列表时**退出码 0 + 输出「数据总量: 0B」**；IPv6 不可达时静默失败 | ① 同步前 `baidupcs ls` 预检目录可列出且非空；② 扫描**本轮**新增日志命中致命模式即失败；③ 枚举为 0 直接报错 | ✅ 坏路径返回「网盘目录不可用（获取目录下的文件列表）… 文件不存在」 |
| 2 | **P0** | 263 个文件（151 mp3 + 112 lrc）被写到 `music/` 的**外层目录** | 批量下载用 `--saveto + 文件名`，saveto 指向了 `localRoot` 的上一级 | 按远端父目录分组下载，`--saveto` 指向对应的本地子目录 | ✅ 删 2 个嵌套文件后完美还原原路径；music 外 0 个媒体文件 |
| 3 | P1 | 进度显示 `664/2037` 等失真数字 | 统计**整个日志文件**的「准备下载/下载完成」行数（历次运行+重试累加） | 只统计本轮日志区间 + 按文件路径去重 + 分母用本轮计划数 | ✅ 显示 `2/425` |
| 4 | P1 | 远端枚举恒为 0 个文件（同步空转） | `baidupcs tree` 输出**相对路径 + 树形缩进**，旧解析按绝对前缀匹配恒不命中 | 按缩进用「父目录栈」重建相对路径再拼远端根；枚举 0 时报错 | ✅ 单测覆盖 + 实测 425 |
| 5 | P1 | 页面「同步中」瞬间变「空闲」、取消按钮失效 | 服务器上装的是**旧版助手二进制**（返回硬编码空闲快照） | 重新构建部署助手，状态字段回归正常 | ✅ `running/mode/elapsed/done/total` 正常 |
| 6 | P1 | 下载大量重试、部分文件失败 | 百度 CDN 域名同时有 A/AAAA，机器无 IPv6 出口，Go 解析器优先 IPv6 | `/etc/hosts` 固定 IPv4 + 内核持久禁用 IPv6 + 「网络类错误仅在本轮 0 产出时判失败」（避免误报） | ✅ 下载恢复正常，重试不再导致失败 |
| 7 | P2 | 点击「删除」页面崩溃（React #130） | react-admin `Button` 内部 `cloneElement(children)`，传字符串子节点产生 `type: undefined` | 对话框按钮改用 MUI `Button` | ✅ 弹窗正常 |
| 8 | P2 | 删除按钮只有图标、无可访问名称 | MUI `Button` 不渲染 `label`，且原实现未设 `aria-label` | 批量栏按钮改用 react-admin `Button`（label + 图标），并加 `aria-label` | ✅ 显示「删除」 |
| 9 | P2 | 日志单文件无限增长；日志面板卡顿 | 单文件追加 + 每 5 秒**整文件扫描**取尾部 | 按天分文件 + **倒读固定块**取尾部 + 噪音过滤/直链压缩 + 保留 7 天自动清理 | ✅ 目录分天、日期可切换 |
| 10 | P2 | 手动同步后调度器立即补跑一次同步 | daily 判重只看 `LastRunDay`，手动同步未写入 | 同步成功后写入 `LastRunDay/LastRunTime` | ✅ `nextRun` 跳到次日 |
| 11 | P3 | 回收站条目 `size` 恒为 0 | 在 `moveFile` **之后**才 stat 源文件 | 移动前先取大小 | ✅ `size=481649` |
| 12 | P3 | 日志混入 `[ undefined]` 等噪音行 | baidupcs 非 TTY 输出残留 | `cleanLogLine` 清理 + 过滤 | ✅ 面板干净 |
| 13 | P3 | 日期下拉混入归档文件名 | 日期列表未校验文件名格式 | 只返回可解析为 `YYYY-MM-DD` 的文件 | ✅ 只列日期 |

## 六、未覆盖项与风险
