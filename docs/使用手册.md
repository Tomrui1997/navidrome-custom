## 三、百度网盘同步（自建功能）

### 3.1 功能入口

登录管理员账号后，点击左侧导航 **「同步」**（地址 `/sync`）。

页面从上到下依次为：

1. **状态区** —— 网盘账号、任务状态、上次同步、下次计划
2. **操作区** —— 立即同步 / 全量校验（覆盖）/ 取消 / 自动刷新
3. **同步设置** —— 全部可配置项（保存后即时生效）
4. **同步日志** —— 按日期回看
5. **回收站** —— 恢复 / 彻底删除

### 3.2 状态区说明

| 显示项 | 含义 |
| --- | --- |
| 网盘账号 | 已登录时显示网盘用户名与 uid；未登录时提示「网盘账号未登录（请先在服务器上登录）」 |
| 任务状态 | `空闲` 或 `同步中`。同步中会显示当前阶段、`已处理 x/y`、`跳过 n`、已耗时 |
| 上次同步 | 最近一次同步的结束时间与结果 |
| 下次计划 | 定时同步的下次执行时间 |

**同步阶段提示**（用于判断是否卡死）：

| 阶段显示 | 含义 | 正常耗时参考 |
| --- | --- | --- |
| 正在准备同步… | 初始化 | 瞬时 |
| 正在检查网盘目录… | 预检远端目录是否存在且非空 | 数秒 |
| 正在枚举网盘文件… | 递归列目录、计算本轮计划文件数 | **约 1–3 分钟**（视目录数量） |
| 正在下载（已存在的文件自动跳过）… | 实际下载，文件名已存在则跳过 | 视文件量与带宽 |
| 同步完成 / 同步失败 | 结束状态 | — |

> ⚠️ **枚举阶段长时间停在 `0/0` 是正常现象**，百度接口逐目录往返，约 65 个目录需要 70 秒左右。此阶段日志不增长、CPU 很低，**不是卡死**，请勿重复点击同步。

### 3.3 首次使用：登录网盘账号

登录态保存在**服务器**上（root 用户的 `BaiduPCS-Go` 配置），Web 页面不接触、也不保存任何网盘凭据。

由运维在服务器执行（**不支持扫码登录**，仅支持账号密码 / BDUSS / Cookie）：

1. 准备网盘登录凭据（Cookie 或 BDUSS）
2. 在服务器上执行登录脚本（凭据只走文件，登录后立即销毁文件）
3. 登录成功后回到「同步」页面，点击「自动刷新」或刷新浏览器，状态区即显示网盘账号

**切换账号**：先在服务器执行 `baidupcs logout`，再用新凭据重新登录。

**前置条件**：网盘上必须存在目录 `/apps/Cloud Sync/music`（百度网盘网页端侧边栏「同步」对应的目录），否则同步会在预检阶段明确失败。

### 3.4 手动同步

| 按钮 | 行为 |
| --- | --- |
| **立即同步** | 增量同步：已存在的文件自动跳过，只下载新增/缺失的文件 |
| **全量校验（覆盖）** | 重新下载并覆盖同名文件。用于网盘**替换过同名文件**、但本地仍是旧版本的情况 |
| **取消** | 终止当前同步任务（按进程组终止，不会残留子进程） |
| **自动刷新** | 开启后页面定时刷新状态（同步中可以观察进度） |

同步完成后 Navidrome 的 Watcher 会**自动扫描**新落地的文件，无需手动触发扫描。

### 3.5 定时同步

| 配置项 | 说明 |
| --- | --- |
| 定时同步 | 总开关 |
| 定时模式 | `每天固定时间` 或 `每 N 分钟` |
| 时间（HH:MM） | 每天模式使用，默认 `03:00` |
| 间隔（分钟） | 间隔模式使用 |

- 调度由助手内置执行（**改完即生效，无需重启服务**）
- 默认定时早于 Navidrome 03:30 的库扫描，保证扫描能看到新文件
- 若手动同步成功，会同步更新「上次同步/下次计划」，避免调度器立即补跑

### 3.6 同步设置（逐项说明）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用同步 | 开 | 关闭后定时任务不再执行 |
| 网盘路径 | `/apps/Cloud Sync/music` | 同步源目录。**默认锁定**，修改需先关闭「锁定路径」 |
| 本地音乐目录 | `/opt/navidrome/music` | 落地目录。**默认锁定** |
| 锁定路径 | 开 | 防止页面误改导致同步范围跑偏（推荐保持开启） |
| 包含歌词（.lrc） | 开 | 是否同步歌词文件 |
| 包含封面图片 | 开 | 是否同步封面图片 |
| 排除目录 | `attachments` | 相对网盘路径，多个用英文逗号分隔；这些目录**不扫描、不下载** |
| 单文件线程数 | 16 | 每个文件的下载线程数。**非 SVIP 建议降到 4** |
| 并行文件数 | 4 | 同时下载的文件数。**非 SVIP 建议降到 2** |
| 软删除（移入回收站） | 开 | 见第四章 |
| 回收站保留天数 | 30 | 超期自动清理 |
| 网盘回收目录 | `/_deleted` | 网盘侧软删除的落点 |
| 日志保留天数 | 7 | 同步日志按天分文件，超期自动清理 |
| 单次同步文件数上限 | 0（不限） | **仅供验证使用**：填 10 可只跑前 10 个文件。**正式运行必须保持 0** |

> 线程数 × 并行文件数 = 总连接数。默认 16 × 4 = 64 连接，按 SVIP 带宽设定；普通账号连接数过高可能被限速，建议降到 4 × 2。

**同步范围规则（固定，不可通过页面绕过）**：

- 只抓以下扩展名：
  - 歌曲：`.mp3` `.flac` `.m4a` `.aac` `.wav` `.ogg` `.opus` `.wma` `.ape`
  - 歌词：`.lrc`
  - 封面：`.jpg` `.jpeg` `.png` `.webp`
- 其他类型文件（如视频、文档、图片）一律跳过
- 按**远端父目录分组**下载，文件落到本地对应的子目录（不会堆在音乐目录外层）
- 默认**只增不减**：网盘删掉的文件，本地不会自动删除（如需清理请用「歌曲删除」功能）

### 3.7 同步日志

- 日志**按天分文件**存放，页面顶部可按日期选择回看
- 已过滤无意义噪音（逐文件元数据、超长下载直链压缩为 `<url>`，**保留错误原因**）
- 日志尾部读取采用倒读固定块，日志变大也不会卡页面
- 保留天数由「日志保留天数」控制（默认 7 天）

### 3.8 回收站

| 列 | 说明 |
| --- | --- |
| 标题 | 歌曲标题 |
| 路径 | 原文件路径 |
| 删除时间 | 进入回收站的时间 |
| 操作人 | 执行删除的账号 |

| 操作 | 行为 |
| --- | --- |
| **恢复** | 本地文件回到原位置；若网盘侧也删了，会一并从网盘回收目录移回 |
| **彻底删除** | 从回收站永久移除（可选是否同时删除网盘回收目录中的文件） |

超过「回收站保留天数」的记录会自动清理。

## 四、歌曲删除（自建功能）

### 4.1 入口

进入 **歌曲** 列表 → 勾选一首或多首 → 点击批量操作栏的 **「删除」** 按钮。

### 4.2 删除范围（三选项）

| 选项 | 说明 | 默认 |
| --- | --- | --- |
| 从音乐库中移除（删除数据库记录） | 仅让歌曲从 Navidrome 中消失，磁盘文件保留 | ✅ 勾选 |
| 删除本地文件 | 删除服务器 `music` 目录下的文件 | ✅ 勾选 |
| 删除百度网盘上的文件 | 同时删除网盘源文件（可从网盘回收站恢复） | ⬜ 未勾选 |

> 默认只操作「库记录 + 本地文件」，**不会误删网盘**。如需同步清理网盘，请手动勾选第三项。

### 4.3 干跑预演（Dry Run）

打开删除对话框时会**自动预演**，逐首显示：

- 本地将要执行的动作与目标路径
- 网盘将要执行的动作与目标路径（如 `/apps/Cloud Sync/music/...`）
- 状态：待执行 / 已完成 / 已跳过 / 失败

**勾选范围变化时会自动重新预演**，确认无误后再点确认删除。

### 4.4 软删除优先

默认开启软删除（推荐保持）：

| 位置 | 软删除行为 | 恢复方式 |
| --- | --- | --- |
| 本地 | 移入 `trash/files/…` | 「同步」页面 → 回收站 → 恢复 |
| 网盘 | 移动到 `/_deleted/…` | 「同步」页面 → 回收站 → 恢复，或网盘自行找回 |

> 配置开启软删除时，即使请求硬删除也会被**强制改回软删除**（安全兜底），避免误删不可恢复。

### 4.5 审计日志

所有破坏性操作（删除 / 恢复 / 彻底删除）都会写入服务器审计日志 `/var/log/nd-helper-audit.log`，含操作人、时间、对象与结果。

## 五、常见问题（FAQ）

**Q1：页面显示「同步完成」，但一个文件都没下载？**
已内置防护：同步前会**预检远端目录**，结束后会**扫描本轮日志**判定成败，杜绝「数据总量 0B + 退出码 0」的假成功。
若仍出现，请看同步日志中的失败原因（如凭据失效、目录不存在）。

**Q2：进度长时间停在「正在枚举网盘文件…」不动？**
属正常。百度接口需逐目录往返，约 65 个目录 ≈ 70 秒。
另外**后台标签页会被浏览器节流**（定时刷新间隔变长），看起来像页面卡住，切到前台即可。

**Q3：下载大量失败、提示网络不可达？**
服务器**无 IPv6 出口**，而部分域名会优先解析到 IPv6，导致连接失败。已通过 `/etc/hosts` 固定 IPv4 解决。
若更换服务器或网络环境，需重新执行 IPv4 固定脚本。

**Q4：下载速度慢 / 被限速？**
把「单文件线程数」降到 4、「并行文件数」降到 2（普通账号连接数过高会被限速）。
注意：小文件（如 `.lrc`）受「每文件一次请求」的延迟限制，提高**并行文件数**的收益大于提高单文件线程数。

**Q5：网盘上替换了同名文件，本地还是旧版本？**
增量同步会跳过同名文件。请用 **「全量校验（覆盖）」** 重新下载覆盖。

**Q6：误删了歌曲，能找回吗？**
能。开启软删除时：本地在 `trash/`、网盘在 `/_deleted/`，都可在「同步」页面的**回收站**里恢复。
超过保留天数（默认 30 天）会被自动清理。

**Q7：页面提示「只有管理员可以进行网盘同步管理」？**
同步与删除功能仅限管理员账号，请用 `admin` 登录。

**Q8：同步任务突然不见了，显示「上次同步被中断」？**
服务重启会中断进行中的同步，页面会标记「上次同步被中断（服务重启）」。重新点击「立即同步」即可，增量同步会自动跳过已下载的文件。

**Q9：本地有 `.lrc` 歌词文件，页面上却没有歌词？**
Navidrome 会自动读取同目录同名歌词文件；若文件名不匹配则读不到。请确认歌词文件名与音频文件名一致（仅扩展名不同）。

**Q10：同步会不会把网盘上没有的本地文件删掉？**
不会。默认**只增不减**，本地文件只能通过「歌曲删除」功能删除。

## 六、注意事项与限制

1. **权限**：同步、删除、回收站均为**管理员专用**，接口层已做校验（未登录调用返回 `Not authenticated`）。
2. **凭据安全**：百度网盘凭据只保存在服务器 root 下（`BaiduPCS-Go` 配置目录），Web 进程全程不接触；请勿把凭据粘贴到聊天、日志或命令行中。
3. **路径锁定**：同步源目录与本地目录默认锁定，避免误改导致同步范围跑偏。
4. **建议保留软删除**：软删除可恢复，硬删除不可逆。
5. **带宽**：生产服务器出口带宽有限，首次全量同步（GB 级）耗时较长，建议安排在夜间由定时任务完成。
6. **磁盘**：本地音乐目录与回收站都会占用磁盘空间，请定期检查；回收站超期自动清理。
7. **单次同步文件数上限**：正式运行**必须保持 0（不限）**，仅在验证流程时填小值。
8. **同名文件**：网盘替换同名文件时本地不会自动更新（需「全量校验（覆盖）」）。
