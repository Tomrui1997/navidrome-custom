## 一、背景与目标

歌曲文件存放在百度网盘 `/apps/Cloud Sync/music`，需要「一键/定时」同步到服务器本地音乐库并自动入库；同时需要在音乐库里删除歌曲时，可同步删除本地文件与网盘文件。

**目标**：把「网盘 → 服务器」的搬运与「库 → 网盘」的删除都收进 Navidrome 管理后台，配置化、可观测、可回滚（软删除）。

## 二、需求优先级（MoSCoW）

| 编号 | 需求 | 优先级 | 说明 |
| --- | --- | --- | --- |
| R1 | 侧边栏新增「同步」入口，页面可配置同步参数 | **Must** | 配置项：网盘路径、本地目录、歌词/封面开关、线程与并发、定时规则、回收站保留天数、日志保留天数 |
| R2 | 手动同步 + 定时同步，均采用**增量** | **Must** | 已存在文件跳过；定时为 daily/interval 两种模式 |
| R3 | 歌曲列表支持**单选/多选删除** | **Must** | 批量操作栏按钮 + 对话框 |
| R4 | 删除范围可选：仅库记录 / 删本地 / 删网盘 | **Must** | 默认勾选「库记录 + 本地」，网盘默认不勾 |
| R5 | 删除走**软删除**可恢复 | **Should** | 本地进 `trash/`，网盘进 `/_deleted/`；页面回收站可恢复/彻底删除 |
| R6 | 同步范围**钉死**在音乐目录，不扫描/下载其他目录 | **Must** | 路径锁定 + 排除目录 + 扩展名白名单 |
| R7 | 同步/删除**仅管理员**可用 | **Must** | 路由挂 adminOnlyMiddleware，前端菜单按权限隐藏 |
| R8 | 同步日志**按天分文件**、可回看、自动清理 | **Should** | 避免单文件无限增长导致页面卡死 |
| R9 | 默认界面语言为**简体中文** | **Could** | 自建分支设定 |
| R10 | 网盘删除支持**硬删**（不可恢复） | **Won't（本期）** | 安全考虑，默认强制软删 |

## 三、功能需求与验收标准（Given-When-Then）

### R1 同步页面与配置
- **Given** 我是管理员且已登录，**When** 我打开左侧菜单「同步」，**Then** 看到状态区（网盘账号/任务状态/上次同步/下次计划）、操作按钮、配置表单、同步日志、回收站四块。
- **Given** 页面已加载配置，**When** 我修改「单文件线程数=16、并行文件数=4」并保存，**Then** 提示「设置已保存」，且下次同步按新参数执行。
- **Given** 非管理员登录，**When** 访问 `/sync` 或调用 `/api/baidusync/status`，**Then** 页面提示「只有管理员可以…」、接口返回 401/403。

### R2 手动 + 定时增量同步
- **Given** 本地已存在与网盘同名同大小的文件，**When** 执行同步，**Then** 该文件被跳过（日志出现「文件已经存在」），不重复下载。
- **Given** 网盘新增 1 个文件，**When** 执行同步，**Then** 本地出现该文件，且页面进度显示 `已完成/计划总数`（分母=本轮目标文件数）。
- **Given** 定时模式为 daily 且时间为 03:00，**When** 到达该时间且当天尚未同步，**Then** 自动触发同步；当天已同步（含手动）则不再重复触发（`LastRunDay` 判重）。

### R3/R4 删除与范围
- **Given** 我在歌曲列表勾选 1 首，**When** 点击「删除」，**Then** 弹窗显示将执行的动作（本地/网盘/库记录），且为 dry-run 预演结果。
- **Given** 我勾选「删除百度网盘上的文件」，**When** 预演刷新，**Then** 显示网盘目标路径（形如 `/apps/Cloud Sync/music/…`）。
- **Given** 我确认删除且范围为「库记录+本地」，**When** 执行完成，**Then** 提示「已删除 N 项，删除数据库记录 M 条」，列表减少 N 行，本地文件移入 `trash/files/…`。

### R5 软删除与恢复
- **Given** 已开启软删除，**When** 我在删除请求里传 `soft=false`，**Then** 服务端强制按软删除执行（不得真删）。
- **Given** 回收站有 1 条记录，**When** 我点「恢复」，**Then** 文件回到原路径、索引条目清空、Navidrome 扫描后曲目重新出现。

### R6 范围锁定
- **Given** `lockPaths=true`，**When** 通过接口提交不同的 `remoteRoot`，**Then** 返回「同步路径已锁定，不允许修改」，配置保持不变。
- **Given** 网盘存在 `attachments/` 等非音乐目录，**When** 同步，**Then** 该目录下文件不下载；日志显示「远端共 X 个文件，排除目录跳过 Y 个，符合要求的 Z 个」。
- **Given** 本地 `localRoot` 的上一级目录，**When** 同步完成，**Then** 不存在任何下载产生的媒体文件（文件只能落在 `localRoot` 内并按远端目录结构分层）。

### R7 权限
- **Given** 未认证请求，**When** 调用 `/api/baidusync/*` 或 `/api/mediaops/*`，**Then** 返回 `Not authenticated`。

### R8 日志
- **Given** 已完成多次同步，**When** 我查看日志，**Then** 只显示「今天」的日志，且可通过日期下拉切换历史日期。
- **Given** 日志目录存在超过保留天数的文件，**When** 助手启动或每日调度，**Then** 自动删除过期日志并打印清理记录。

### R9 默认中文
- **Given** 全新浏览器（无语言偏好），**When** 打开站点，**Then** 界面默认简体中文（`localStorage.locale=zh-Hans`）。

## 四、非功能需求

| 类别 | 要求 |
| --- | --- |
| 安全 | 百度凭据仅存于 root 的 `baidusync.json`(0640)，Web 进程不接触；路径必须落在 localRoot/remoteRoot 内（防目录穿越）；特权动作走 Unix socket 且动作白名单 |
| 性能 | 同步 1.2GB 实测 ≈ 4.4MB/s（-p 16 -l 4）；日志尾部读取为 O(1) 倒读，不随文件增长变慢 |
| 兼容 | 测试机 CentOS 8 / glibc 2.28（zig 动态链接）；生产 CentOS Stream 9；无 IPv6 出口环境可用 |
| 可观测 | 任务状态（running/mode/elapsed/已完成/计划数）、审计日志（删除/恢复/改配置）、按天同步日志 |
| 可恢复 | 删除可恢复；配置有备份（`/root/baidusync.json.bak*`）；二进制部署有回滚命令与官方备份 |

## 五、明确不做（本期）

- 网盘侧**硬删**（`Won't`）：软删是安全底线。
- 网盘 → 本地的**双向同步/镜像删除**：仅支持「只增不减」，`deleteExtra=false`。
- 多网盘账号、多音乐根目录。
